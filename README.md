# 민기의 모험 (Minki's Adventure)

친구들과 모바일 브라우저로 가볍게 즐기는 2D 덱빌딩 로그라이크 게임입니다.

## 기술 스택
- TypeScript
- Phaser 4
- Vite

## 시작하기

```bash
npm install
npm run dev
```

개발 서버가 실행되면 브라우저에서 안내된 주소로 접속하세요.

### 빌드

```bash
npm run build
```

### 빌드 결과 미리보기

```bash
npm run preview
```
