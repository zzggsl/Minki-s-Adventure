# UI & UX 가이드라인 (UI Guide)

## 1. Top UI (상단 바)
- **위치**: 화면 최상단 고정
- **구성 요소**:
  - `HP`: 플레이어의 현재 체력 / 최대 체력
  - `Floor`: 현재 층수
  - `Deck`: 현재 덱 확인 버튼
  - `Settings`: 설정 버튼 (볼륨, 속도, 기기 UI 강제 변경)

## 2. Bottom UI (하단 바)
- **Draw Pile (좌측 하단)**: 뽑을 카드 더미 (남은 장수 표시)
- **Discard Pile (우측 하단)**: 버린 카드 더미 (버려진 장수 표시)
- 클릭 시 모달(Modal) 창으로 내부 카드 목록을 보여주어야 함.

## 3. Tooltip System (통합 툴팁)
- **사용처**: 카드 부가 효과(방어도, 독 등), 적의 의도(Intent), 버프/디버프 아이콘, 유물 등.
- **디자인**: 어두운 반투명 배경에 텍스트. 특정 키워드(예: 방어도)는 노란색 테두리 텍스트로 하이라이트.

## 4. Cross-Platform UX (플랫폼별 조작 규칙)
- **기기 감지**: `SettingsManager`를 통해 접속 환경(PC/Mobile)을 자동 감지 (설정에서 강제 오버라이드 가능).
- **카드 사용**:
  - `PC`: 호버 시 확대, 드래그 & 드롭으로 사용.
  - `Mobile`: 단일 터치 시 위로 팝업(선택), 그 상태에서 다시 터치하거나 스와이프하여 사용.
- **카드 보상 획득**:
  - `PC`: 카드 클릭 시 즉시 획득 또는 우클릭 확대.
  - `Mobile`: 터치 시 하단에 `[확대]`, `[가져가기]` 버튼 팝업 렌더링 (실수 방지).
