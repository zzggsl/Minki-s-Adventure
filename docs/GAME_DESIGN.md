# 게임 디자인 문서 (Game Design Document)

## 1. 핵심 게임 루프
- **MenuScene (타이틀)** -> **MapScene (경로 선택)** -> **BattleScene (전투)** -> **RewardScene (전리품 선택)** -> **MapScene (복귀)**

## 2. 전투 메커니즘
- **마나 (Mana)**: 매 턴 시작 시 최대치(기본 3)로 회복되며, 카드를 사용할 때 소모됩니다.
- **방어도 (Block)**: 카드를 통해 획득하며, 적의 공격 데미지를 체력 대신 먼저 흡수합니다. 턴이 종료되면 0으로 초기화됩니다.
- **적의 의도 (Intent)**: 적이 다음 턴에 어떤 행동(공격, 방어, 버프 등)을 할지 플레이어에게 미리 보여주어 전략적인 선택을 요구합니다.

## 3. 향후 추가될 핵심 요소 (예정)
- **노드 다양화**: 엘리트 전투, 보스 전투, 휴식(모닥불), 미지의 이벤트 노드 추가.
- **유물 (Relics)**: 게임 내내 지속적인 패시브 효과를 주는 아이템 시스템.
- **상태 이상 (Status Effects)**: 취약, 약화, 화상 등 턴 단위로 적용되는 버프/디버프 시스템.
