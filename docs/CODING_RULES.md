# 코딩 컨벤션 및 규칙 (Coding Rules)

## 1. 엄격한 타입스크립트 (Strict TypeScript)
- `any` 타입 사용을 극도로 지양합니다.
- 복잡한 데이터 구조는 반드시 `src/types/index.ts`에 `interface`나 `type`으로 명시한 후 사용합니다.
- 모듈만 가져올 때는 `import type`을 사용하여 빌드 속도와 안정성을 높입니다.

## 2. 반응형(비율 기반) UI 배치
- 화면에 요소를 배치할 때 특정 기기에 종속된 하드코딩된 좌표(`x: 1734, y: 982` 등)를 절대 사용하지 않습니다.
- 항상 `width`와 `height`를 기준으로 한 비율(`width * 0.5`, `height / 1.2` 등)을 사용하여 어떤 기기에서도 자연스럽게 렌더링되게 합니다.

## 3. 하드코딩 방지
- 중요한 수치(기본 체력, 마나, 뽑는 카드 수 등)는 곳곳에 숫자로 적지 않고 `GameState`의 초기화 로직이나 상수(Constants)로 관리합니다.
