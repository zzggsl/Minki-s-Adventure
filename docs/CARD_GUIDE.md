# 카드 추가 가이드 (Card Guide)

## 1. 카드 데이터 구조
모든 카드는 `ICardData` 인터페이스 형식을 엄격하게 준수해야 합니다.
- `id`: 고유 식별자 (영문 소문자 및 언더스코어)
- `name`: 카드 이름 (한글)
- `cost`: 소모 마나
- `desc`: 카드 설명
- `type`: 'ATTACK' | 'DEFEND' | 'SKILL' | 'POWER'
- `value`: 데미지 또는 방어도 수치 (추후 효과가 복잡해지면 별도의 effect 객체로 분리 예정)

## 2. 파일 분리 원칙 (단일 진실 공급원)
- **10장 이하**: `src/data/cards.ts` 파일 하나에서 모두 관리 (현재 상태)
- **30장 이상**: 파일 분리 고민 시작
- **100장 이상**: 반드시 `basic.ts`, `common.ts`, `rare.ts` 등으로 폴더를 나누어 분리

*주의: 섣부른 파일 분리는 지양하며, 관리가 불편해지는 임계점에 도달했을 때 리팩토링합니다.*
